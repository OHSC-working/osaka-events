# 大阪イベントカレンダー：情報整形Skill

## 処理フロー（毎回この順序・省略禁止）
1. **検索**：キーワードごとに日程・場所・概要・注意事項・予約要否・公式URLなどの一次情報を集める
2. **表にする**：下記21列の形式で初稿を作る
3. **ファクトチェック**：特に開催日・開催有無・予約要否を、別の情報源で再度裏取りする。未発表なら日程ステータスを「予定」に
4. **修正**：食い違いを直して最終版にする
5. **書き込み**：Google Sheetsコネクタでシート末尾に追記（Status＝「公開」、「人間チェック」＝「未チェック」、「AIメモ」＝「Claude記入（日付）：要点」）。スポーツは「スポーツ」タブへ。既存行は「AI編集禁止」にチェックがあれば触らない。コネクタが使えない場合はタブ区切りブロック（ヘッダーなし）を出力する

## 出力列（シートと同じA〜Uの21列・順番固定）
ナンバリング／Status／人間チェック／AI編集禁止／タイトル／開始日／終了日／日程ステータス／定期開催かどうか／エリア／場所・地名／GoogleMap／概要／注意事項／公式URL／予約方法／紹介youtube_English(URL)／画像URL／スポーツイベントかどうか／人間メモ（Claudeは空欄）／AIメモ
- 各列のルールは CLAUDE.md の表に従う
- 画像URL：公式ページのOGP画像URLをそのまま記載（ダウンロードしない）。無ければ空欄
- 確証が持てない項目は憶測で埋めず「要確認」と書く

## 定期チェック時（毎週木曜のルーティン）
- **「AI編集禁止」にチェックがある行は変更しない**
- 公開中の行（特に開催日・開催有無・予約要否）をファクトチェックし、誤りは修正（修正した行は「人間チェック」＝「未チェック」、「AIメモ」に「Claude更新（日付）：変更点」）
- 終了日を過ぎた行は触らない（サイト側で自動的に非表示）
- 新しいローカルイベントは「下書き」で追加して提案（Shoが公開を判断）。スポーツの試合は確定日程なら「公開」で追加
- 中之島公園（バラ園含む）の公式・大阪市の情報を確認し、未登録のイベントを追加
- 開催前の全行の公式URL・画像URLを実際に開いて確認。404・Not Found・トップへの転送・「要確認」は正しいページ／画像に差し替える
- 日程ステータス「予定」または「要確認」を含む行を再確認し、確定情報があれば更新（上書き前に最新値を読む）
- スポーツの新しい試合日程が発表されていれば追加
- 最後に「追加○件／更新○件／変化なし○件」、提案したローカルイベント一覧、Shoが確認すべき行番号を報告する

## 報告時の注意
- 情報は検索時点のもの。公開前に最終確認を促す一言を添える
- 画像URLは外部参照のため、将来リンク切れの可能性がある旨を添える
